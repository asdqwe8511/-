# 선물 자동매매 봇 (Bybit USDT 무기한, 모의 단계)

사주 웹앱과 별개인 폴더입니다. 의존성 없이 Node 18+ 만 있으면 됩니다.
**아직 실주문 코드는 없습니다.** 백테스트와 실시간 모의(공개 시세만 사용)까지입니다.

## 규칙 → 코드

| # | 규칙 | 구현 |
|---|------|------|
| 1 | 가장 강한 지지/저항에 트리거, 모든 코인 | `lib/levels.js` 일봉 전체(최대 1000개) 피벗을 1% 폭으로 묶고 터치 수·최근성·거래량으로 강도 산정. 현재가 아래 최강 지지 = 롱 트리거, 위 최강 저항 = 숏 트리거. 하루 1회 갱신 |
| 2 | 진입가 대비 ±10% 방향 적중 시 손절선만 설정 (익절 없음, 물량 100% 유지) | `lib/strategy.js` OPEN→LOCKED. 손절선 = 최대 이익의 50% 지점 (+10%면 +5%) |
| 3 | 스탑은 1일 1회만 수정 | 24시간마다 최고 이익의 50% 지점으로 재계산, 유리한 방향(롱은 위, 숏은 아래)으로만 이동 |
| 4 | 첫 진입 격리, 시드의 1/10 | `config.js` `seed / entryDivisor` 가 증거금 |
| 5 | 첫 진입은 스탑 없이 청산까지 | OPEN 단계엔 스탑이 없고, 손절선이 생기기 전까지는 청산으로만 끝남 |

모든 숫자(레버리지, 동시 포지션 상한, 수수료 등)는 `config.js` 에서 바꿉니다.

## 실행

```bash
npm run test:bot                  # 로직 테스트 (네트워크 불필요)
node trading-bot/backtest.js 30   # 거래대금 상위 30코인, 최근 ~41일 1시간봉
node trading-bot/paper-bot.js 50  # 실시간 모의 (15초마다 시세, 상태는 paper-state.json)
```

Bybit 공개 API(`api.bybit.com`)에 접속되는 환경에서 돌려야 합니다.

## 알아둘 것

- **스탑 없는 진입 = 손실 상한은 격리 증거금(시드의 1/10)** 입니다. 레버리지 5배면 진입가에서 약 -19.5% 근처에서 청산됩니다. 레버리지를 올리면 청산이 가까워져 "청산까지 방치"가 곧 전액 손실이 됩니다.
- 코인을 전부 감시해도 1/10씩이라 **동시 포지션은 `maxOpen` 개까지**만 엽니다. 수수료 때문에 10번째 칸은 증거금이 모자랄 수 있습니다.
- +10%는 레버리지 5배면 증거금 대비 +50% 입니다. 반대로 -10%에서는 아무것도 하지 않습니다.
- 손절선은 하루 1번만 올라가므로, 하루 안에 급반전하면 올라가기 전 손절선(처음엔 이익 5%)까지 되돌려 맞습니다. 주기를 줄이면 더 촘촘히 지키지만 규칙3과 달라집니다.
- 백테스트는 1시간봉 안에서 시가→저/고→종가 순서로 가정하고, 트리거는 선 가격에 슬리피지만 얹어 체결합니다. 실제보다 낙관적일 수 있습니다.
- 지지/저항 방식(반등 진입)은 추세장에서 선이 뚫리면 계속 불리합니다. 백테스트로 먼저 확인하세요.
