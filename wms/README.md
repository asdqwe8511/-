# 통합물류 WMS — 도서도매 반품 자동화

Edge에 열어 둔 WMS 화면에서 아래 반복 작업을 자동으로 돌리기 위한 스크립트를 모아 둔 곳입니다.

## 자동화하려는 절차

1. **도서도매반품조회/등록** 탭 — `박스번호 채번` 클릭 (여기서 나온 박스번호를 이후 단계에서 계속 씀)
2. **도서도매반품조회/등록** 탭 — `반품등록` 클릭
3. **반출입등록** 탭 — `반입박스번호`에 채번된 박스번호 입력 후 엔터
4. **박스별입고등록** 탭 — `박스번호`에만 채번된 박스번호 입력 (다른 항목은 손대지 않음)
5. **반입내역** — 도서명 전체 체크 후 `등록(F6)` 클릭
6. **도서도매반품조회/등록** 탭으로 복귀 — `초기화` 후 `반품예정번호`에 커서

## 지금 상태

| 파일 | 용도 | 상태 |
|---|---|---|
| `bookmarklet-src/dump.js` | 화면 구조 — **즐겨찾기용. 콘솔 안 씀** | 완성, 검증됨 |
| `00-mini-dump.js` | 화면 구조 — 짧은 버전, 콘솔용 | 완성, 검증됨 |
| `01-dump-structure.js` | 화면 구조 — 자세한 버전, JSON 출력 | 완성, 검증됨 |
| `bookmarklet-src/record.js` | **동작 녹화** — 내가 클릭·입력한 것을 순서대로 기록 | 완성, 검증됨 |
| `bookmarklet-src/run-return.js` | **1~6단계 자동 실행** — 실제 화면(kbwms) 기준 | 완성, 목업 검증됨 |

자동화 스크립트는 화면의 실제 id/name을 알아야 쓸 수 있습니다.
그래서 먼저 `01-dump-structure.js` 로 구조를 뽑습니다.

## 회사 PC에서 — 콘솔 없이 쓰기

개발자 도구를 여는 게 부담스러우면 **즐겨찾기(북마클릿)** 방식을 씁니다.
설치할 것도 없고, 콘솔에 무언가를 입력할 일도 없습니다. 즐겨찾기를 한 번 클릭하면 됩니다.

만드는 법:

```bash
node wms/tools/build-bookmarklet.js wms/bookmarklet-src/dump.js
# → wms/bookmarklet-src/dump.bookmarklet.txt (즐겨찾기 주소 한 줄)
```

쓰는 법: Edge 즐겨찾기 모음에서 우클릭 → **즐겨찾기 추가** →
이름은 아무거나, **URL 칸에 위 한 줄을 붙여넣기** → WMS 화면에서 그 즐겨찾기 클릭.
결과가 화면 위 상자로 뜨고 `전체 복사` 버튼이 있습니다.

단, 이것도 사내 화면에서 직접 만든 스크립트를 돌리는 일입니다.
회사 정책상 괜찮은지는 확인이 필요할 수 있습니다.

## 자동 실행 — 박스번호채번을 누르면 한 바퀴

`run-return.js` 로 만든 즐겨찾기를 WMS 화면에서 누르면 상자가 뜹니다.

1. **[체크박스 지정]** — 처음 한 번만. 반입내역 전체선택 체크박스는 화면에 id 가 없어서
   직접 집어 줘야 합니다. 누르면 십자 커서가 되고, 그 체크박스를 클릭하면 됩니다.
   정한 값은 이 브라우저에 저장돼 다음부터는 안 물어봅니다.
2. **[점검]** — 화면을 바꾸지 않고 필요한 자리를 다 찾을 수 있는지만 봅니다.
3. **[● 대기 시작]** — 이제 화면의 **[박스번호채번]** 을 누르면 2~6단계가 이어서 돕니다.
   한 바퀴 돌고 반품예정번호에 커서가 오면 멈추고 다시 대기합니다.
   다음 건은 채번만 누르면 됩니다.

이 화면의 그리드는 줄을 미리 그려 두고 값만 채운다. 그래서 "줄이 늘어나면 조회된 것"
같은 신호가 오지 않는다. 조회를 기다리는 대신 전체선택을 눌러 보고 실제로 걸렸는지
확인하고, 안 걸렸으면 다시 누른다.

이 화면은 확인창이 브라우저 팝업이 아니라 화면 안 버튼(`alert2_wframe_btn_confirm` 등)이라
자동화가 그 버튼도 눌러야 합니다. 아무 창이나 누르면 위험하므로,
`CFG.okDialogs` 에 적힌 문구가 뜬 창만 누르고 **모르는 문구면 멈추고 보여 줍니다.**

## 절차를 녹화해서 알려 주기

`record.js` 로 만든 즐겨찾기를 누르고 `● 녹화` → 평소대로 작업 → `■ 정지` → `복사`.
어떤 버튼을 눌렀고 어느 칸에 무엇을 넣었는지, 서버가 채워 준 값까지 순서대로 남습니다.

```
[00:00] top>0:mainFrame 클릭 button #btnBoxSeq "박스번호 채번"
[00:01] top>0:mainFrame 화면변화 input/text #txtBoxNo (박스번호) = "BX26090001"
[00:01] top>0:mainFrame 키 Enter input/text #txtInBoxNo (반입박스번호) = "BX26090001"
```

`값 가리기` 를 켜면 도서명·번호가 `●●●` 로 바뀌어 복사됩니다.
기록은 sessionStorage 에 남아서, 화면이 새로 떠도 즐겨찾기를 다시 누르면 이어서 적습니다.

## 1단계 — 화면 구조 뽑기

1. Edge에서 WMS 화면을 연 채로 `F12` → **Console** 탭
2. 콘솔에 붙여넣기가 막혀 있으면 `allow pasting` 을 입력하고 엔터
3. `00-mini-dump.js`(짧은 버전) 또는 `01-dump-structure.js`(자세한 버전) 내용을 **전체 선택 → 복사 → 콘솔에 붙여넣기 → 엔터**
4. 짧은 버전은 결과가 콘솔에 바로 보이고, `copy(__D)` 로 클립보드에 담깁니다.
   자세한 버전은 `copy(__WMS_DUMP_JSON)` 입니다
5. 그 내용을 붙여넣어 주시면 2단계 스크립트를 작성합니다

가능하면 **각 탭을 한 번씩 열어 본 뒤** 실행해 주세요.
탭 내용을 클릭할 때 비로소 그리는 화면이면, 열어 보지 않은 탭은 덤프에 안 잡힙니다.
탭마다 따로 실행해서 3개 결과를 주셔도 됩니다.

이 스크립트는 **읽기만 합니다.** 클릭·입력·저장을 하지 않습니다.

## 테스트

`test/` 에 실제 화면을 흉내 낸 목업과 검증 스크립트가 있습니다.
목업은 프레임 구조·`th/td` 라벨 배치 등 한국 SI 화면에서 흔한 형태를 따라 만든 것이고,
실제 WMS와 id가 같지는 않습니다. 스크립트가 브라우저에서 오류 없이 도는지 확인하는 용도입니다.

```bash
npm i -D playwright
(cd wms/test/fixture && python3 -m http.server 8899 &)
node wms/test/run-dump.js
node wms/test/run-mini.js
node wms/test/run-bookmarklet.js
node wms/test/record-test.js
node wms/test/run-return-test.js
```

미리 설치된 브라우저를 쓰려면 `PW_CHROME=/opt/pw-browsers/chromium-1194/chrome-linux/chrome` 를 앞에 붙입니다.
