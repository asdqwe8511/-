# 통합물류 WMS — 도서도매 반품 자동화

Edge에 열어 둔 WMS 화면에서 아래 반복 작업을 자동으로 돌리기 위한 스크립트를 모아 둔 곳입니다.

## 자동화하려는 절차

1. **도서도매반품조회/등록** 탭 — `박스번호 채번` 클릭 (여기서 나온 박스번호를 이후 단계에서 계속 씀)
2. **도서도매반품조회/등록** 탭 — `반품등록` 클릭
3. **반출입등록** 탭 — `반입박스번호`에 채번된 박스번호 입력 후 엔터
4. **박스별입고등록** 탭 — `박스번호`에만 채번된 박스번호 입력 (다른 항목은 손대지 않음)
5. **반입내역** — 도서명 전체 체크 후 `등록(F6)` 클릭
6. **도서도매반품조회/등록** 탭으로 복귀 — `초기화` 후 `반품예정번호`에 커서

## 지금 상태

| 파일 | 용도 | 상태 |
|---|---|---|
| `01-dump-structure.js` | 화면 구조(탭·입력창·버튼·그리드) 수집 | 완성, 검증됨 |
| `02-run-return.js` | 위 1~6단계 실행 | 화면 구조 확인 후 작성 |

자동화 스크립트는 화면의 실제 id/name을 알아야 쓸 수 있습니다.
그래서 먼저 `01-dump-structure.js` 로 구조를 뽑습니다.

## 1단계 — 화면 구조 뽑기

1. Edge에서 WMS 화면을 연 채로 `F12` → **Console** 탭
2. 콘솔에 붙여넣기가 막혀 있으면 `allow pasting` 을 입력하고 엔터
3. `01-dump-structure.js` 내용을 **전체 선택 → 복사 → 콘솔에 붙여넣기 → 엔터**
4. 안내대로 `copy(__WMS_DUMP_JSON)` 을 실행하면 결과가 클립보드에 담깁니다
5. 그 내용을 붙여넣어 주시면 2단계 스크립트를 작성합니다

가능하면 **각 탭을 한 번씩 열어 본 뒤** 실행해 주세요.
탭 내용을 클릭할 때 비로소 그리는 화면이면, 열어 보지 않은 탭은 덤프에 안 잡힙니다.
탭마다 따로 실행해서 3개 결과를 주셔도 됩니다.

이 스크립트는 **읽기만 합니다.** 클릭·입력·저장을 하지 않습니다.

## 테스트

`test/` 에 실제 화면을 흉내 낸 목업과 검증 스크립트가 있습니다.
목업은 프레임 구조·`th/td` 라벨 배치 등 한국 SI 화면에서 흔한 형태를 따라 만든 것이고,
실제 WMS와 id가 같지는 않습니다. 스크립트가 브라우저에서 오류 없이 도는지 확인하는 용도입니다.

```bash
npm i -D playwright
(cd wms/test/fixture && python3 -m http.server 8899 &)
node wms/test/run-dump.js
```

미리 설치된 브라우저를 쓰려면 `PW_CHROME=/opt/pw-browsers/chromium-1194/chrome-linux/chrome` 를 앞에 붙입니다.
