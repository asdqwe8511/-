# 무손절 농장 전략 시뮬레이터

코인판 매매일지에서 본 전략 — 여러 종목에 롱숏을 같이 깔아 두고(농장), 추세가
확인된 것만 들어가고, 밀리면 손절 대신 물을 타고, 목표가에 닿은 것만 파는 방식 —
을 그대로 코드로 옮긴 것이다. 5천 달러가 141일 만에 5배가 됐다는 얘기가 어떤
조건에서 성립하는지, 같은 규칙으로 다른 시장을 만났다면 어떻게 됐을지 세어 본다.

**이건 매매 권유가 아니고 수익을 약속하는 도구도 아니다.** 규칙을 숫자로 바꿔 놓고
"이 규칙이면 이런 일도 생긴다"를 보여 주는 계산기다.

## 돌려 보기

```bash
node trading/backtest.js                        # 한 번 돌리고 성적표
node trading/backtest.js --seed 460             # 글에 나온 모양(5배 + 큰 낙폭)에 가까운 판
node trading/backtest.js --seed 2               # 청산당하는 판
node trading/backtest.js --runs 500             # 시장만 바꿔 가며 500번, 분포 보기
node trading/backtest.js --compare --runs 500   # 규칙을 하나씩 바꿔 가며 비교
node trading/backtest.js --csv ./data           # 진짜 데이터로
node trading/test-strategy.js                   # 엔진 점검 37가지
```

옵션: `--days 141 --leverage 3 --stop 0.2 --cap 0.25 --stress 0.7 --symbols 8`
`--seed-equity 5000 --rebound 0.35 --no-funding --no-dca --json`

## 글의 규칙이 코드 어디에 있나

| 글에 적힌 말 | 코드 | 기본값 |
|---|---|---|
| 추세가 나오기 전엔 안 들어간다 | `trendSeries()` — 이동평균 10/30 + 연속 확인 | 3일 연속 |
| 숏은 더 늦게 | `shortExtraConfirm` | +2일 |
| 한 파동을 통째로 간다 | 목표가 전엔 안 판다. 추세가 꺾여도 이익 난 자리만 정리 | `takeProfitOnFlip` |
| 역방향이면 물량을 모은다 | 평단에서 12% 밀릴 때마다 추가 매수 | 최대 3회 |
| 종목당 시드의 25% | `symbolCapPct` — 넣는 순간마다 검사 | 0.25 |
| 롱숏을 같이 들되 주방향이 크다 | 지수 추세와 같은 방향이면 `mainWeightPct`, 반대면 `subWeightPct` | 8% / 3.5% |
| 목표가에 닿은 것만 판다 | 주방향 +35%, 보조방향 +10% (평단 기준, 물타면 같이 내려온다) | |
| 아침에 한 번만 본다 | 하루 한 번, 종가에서만 결정. 하루 새 자리 2개까지 | |
| 익절만 합니다, 손절 안 합니다 | `stopLossPct: null` | 무손절 |

글에 없지만 계좌를 실제로 망가뜨리는 것들도 넣었다.

- **교차마진 청산** — 자산이 유지증거금 밑으로 내려가면 전부 날아간다. 무손절의
  진짜 상대는 하락이 아니라 이것이다.
- **펀딩비** — 추세를 따라간다. 오르는 중이면 롱이 낸다. 오래 들고 있을수록 쌓인다.
- **수수료** — 진입·청산 각 0.05%.

## 한 판 보기

```
$ node trading/backtest.js --seed 460

최고점                     $30,352 (6.07배)
끝                         $29,923 (5.98배)
최대낙폭(MDD)              -74.6% — 69일차
최악의 하루                -40.7% — 69일차
정리한 매매            33건, 이긴 비율 100%
안 판 자리의 평가손익                $3,850

가장 험했던 6일: 63일차 → 69일차, -68.5% ($4,592 → $1,448)
```

**이긴 비율 100%가 이 전략의 지문이다.** 실력이 아니라, 진 자리를 안 팔았기 때문에
매매 통계에 안 잡히는 것이다. 손실은 '안 판 자리' 안에 평가손실로 살아 있다.
그래서 리포트에 그 숫자를 따로 찍는다.

## 500번 돌리면

같은 규칙, 시장만 바꿔 가며 141일씩 500번 (배율 3배, 무손절):

| | |
|---|---|
| 청산당한 비율 | 45% |
| 원금도 못 지킨 비율 | 57% |
| 5배 이상 간 비율 | 11% |
| 배수 중앙값 | 0.43배 |
| 배수 평균 | 1.88배 |
| MDD 중앙값 | -84% |
| 5배 간 계좌들의 MDD 중앙값 | -33% |

평균 1.88배와 중앙값 0.43배가 같이 있는 게 전부다. 소수의 대박이 평균을 끌어올린다.
일지를 올리는 사람은 살아남은 11%에서 나오고, 청산당한 45%는 일지를 안 쓴다.

## 규칙을 하나씩 바꾸면 (각 500번, 같은 시장 씨앗)

| 변형 | 청산률 | 중앙배수 | 상위5%배수 | 5배+ | MDD중앙 |
|---|---|---|---|---|---|
| 원본: 무손절 3배 | 45% | 0.43 | 8.21 | 11% | -84% |
| 무손절 2배 | 28% | 0.99 | 4.61 | 4% | -58% |
| 무손절 1배 | 9% | 1.09 | 2.29 | 0% | -32% |
| 손절 -20% | 0% | 1.91 | 6.39 | 10% | -29% |
| 손절 -50%(한 번 물탄 뒤) | 0% | 1.84 | 7.65 | 13% | -43% |
| 물타기 없음(무손절) | 26% | 1.08 | 5.96 | 7% | -50% |
| 종목당 한도 10% | 32% | 1.05 | 6.62 | 8% | -55% |
| 추세확인 없이 진입 | 50% | 0.00 | 7.31 | 10% | -100% |

이 모델에서 나온 세 가지.

1. **손절선은 위쪽을 별로 안 깎는다.** 손절 -20%은 청산률을 45%에서 0%로 내리면서
   5배 이상 갈 확률은 11%에서 10%로 거의 그대로다. 잘라 낸 건 대박이 아니라 파산이다.
2. **추세 확인이 규칙 중에 제일 값어치가 있다.** 그것만 빼면 중앙배수가 0이 된다.
   글쓴이가 "숏은 추세 확인 전엔 안 친다"고 못 박은 게 괜한 말이 아니다.
3. **배율이 청산률을 정한다.** 규칙이 같아도 1배는 9%, 3배는 45%다.

## 되돌림이 있어야 산다

무손절은 "기다리면 되돌아온다"에 걸린 전략이다. 그래서 시장 생성기에 되돌림 세기를
넣어 뒀다(`--rebound`, 크게 빠진 뒤 며칠에 걸쳐 얼마나 되돌리는가).

되돌림이 잦은 시장으로 바꾸면 청산률이 50% → 33%, 중앙배수가 0.16 → 1.22로 움직인다.
전략이 좋아진 게 아니라 시장이 바뀐 것이다. 그리고 되돌림이 아무리 커도 청산률이 0이
되진 않는다. **청산당한 뒤에 오는 되돌림은 아무 소용이 없기 때문이다.**

## 믿으면 안 되는 부분

- **가짜 시장이다.** 국면이 바뀌는 랜덤 시장으로, 일간 변동성은 실제 알트와 비슷하게
  (표준편차 5.7%/일, 연 110%) 맞춰 놨지만 실제 코인 가격이 아니다. 진짜 결론을
  원하면 `--csv` 로 진짜 데이터를 넣어야 한다.
- **목표가는 닿으면 체결됐다고 친다.** 지정가라 대체로 맞지만 낙관적인 쪽이다.
- **청산 판정은 반대로 비관적이다.** 하루 안에 모든 종목이 동시에 최악의 순간을 맞았다고
  본다(`--stress`, 1이면 전부 저점/고점 동시, 0.7이 기본). 슬리피지·부분청산·거래소별
  청산 방식은 안 넣었다.
- **사람이 안 들어 있다.** 78% 빠진 계좌에 물을 더 타는 손은 코드로만 쉽다.
- **씨앗을 골라서 아무 얘기나 만들 수 있다.** seed 460 은 5.98배, seed 2 는 0배다.
  한 판은 증거가 아니다. 그래서 `--runs` 가 있다.
